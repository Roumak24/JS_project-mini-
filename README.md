# 🧺 LaundryPro – Laundry Service Website

A responsive laundry service website built using **HTML, CSS and Vanilla JavaScript**. This project demonstrates DOM manipulation, dynamic content generation, event handling, shopping cart functionality and form validation.

Users can explore laundry services, add or remove services from their cart, view the total price and complete a demo booking.

## 📸 Project Overview

LaundryPro provides a simple and user-friendly interface for booking laundry services online. The website allows users to select services, manage their cart and receive a booking confirmation through a front-end demonstration.

## ✨ Features

- **Dynamic Service Rendering:** Laundry services are generated dynamically using JavaScript.
- **Add to Cart:** Add multiple laundry services to the cart.
- **Remove from Cart:** Remove previously selected services.
- **Real-Time Price Calculation:** Automatically calculates the total amount based on selected services.
- **Cart Management:** Displays selected services with serial numbers, names and prices.
- **Form Validation:** Validates customer name, email address and phone number.
- **Booking Confirmation:** Displays a confirmation message with customer and booking details.
- **Responsive Design:** Adapts to different screen sizes using CSS media queries.
- **Smooth Navigation:** Smooth scrolling between different sections of the website.

## ⚙️ Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/LaundryPro.git
```

### 2. Navigate to the Project Directory

```bash
cd LaundryPro
```

### 3. Open the Project

Open the project folder in Visual Studio Code.

### 4. Run the Website

- Install the Live Server extension in VS Code.
- Right-click on `index.html`.
- Select **Open with Live Server**.

The website will open in your default browser.

## 🧠 JavaScript Concepts Implemented

This project helped me practice and understand several important JavaScript concepts:

- DOM Selection using `getElementById()`.
- Dynamic HTML generation using `createElement()` and `innerHTML`.
- Event handling using `addEventListener()`.
- Array manipulation using `push()` and `filter()`.
- Array methods such as `forEach()`, `find()`, `some()` and `reduce()`.
- Conditional statements and functions.
- Form validation using Regular Expressions.
- Updating webpage content dynamically without reloading the page.

## ⚠️ Current Limitations

- Booking confirmation is currently a front-end demonstration.
- No backend or database is connected.
- Customer booking information is not permanently stored.
- Email notifications and actual payment processing are not implemented.
- The newsletter subscription form is currently a UI element only.
